    開啟 Minecraft Java Edition，選擇「多人遊戲」。

  2. 2

    新增伺服器，名稱可以填寫「星鈴町」。

  3. 3

    輸入 haowan.pro 後即可連線。

支援 Java 1.21 - 26.2

    連接埠填入 18492，儲存後加入。
